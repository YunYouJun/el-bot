# @el-bot/commands

私有工作区包，为 `el-bot` 和 `@el-bot/dsh` 提供同一套命令名称索引与注册生命周期：

- 规范名称和别名共享冲突空间，注册失败时不留下半条命令。
- `register()` 返回幂等注销函数，按注册身份清理，不会误删后来注册的同名命令。
- `resolve()` 返回运行时自己的 payload；公共层不执行 handler、不发送消息、不管理权限。
- `list()` 按注册顺序返回隔离快照，并从 Adapter 提供的 `describe()` 投影公共元数据。
- `asMap()` 为不使用别名的旧插件提供同一索引的实时 Map 视图，支持缓存引用、修改、删除和迭代；`getDisposer()` 读取当前注册身份的注销函数，供运行时清理插件登记。

运行时仍各自保留斜杠、昵称、@、权限、去重、会话和回复语义。本包不发布到 npm，构建时由 tsdown 内联到对应产物。
