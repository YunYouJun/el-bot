# 小云的 QQ 创造模式

在小云的官方 QQ 私聊中，已绑定的主人可以发送 `/create`，用聊天消息为自己添加快捷指令，或者起草群图缓存设置。小云会把拟议改动做成确认卡。核对后点击「同意修改」，变更立即生效，无需编辑 YAML 或重启。

例如，发送 `/create` 后说「加个 /cache，查看群图缓存」。确认卡会显示这个指令的用途和可用范围。启用后，即使已经退出创造模式，也可以随时在主人私聊发送 `/cache` 查看当前值。

| 你想做什么 | 发送给小云 |
| --- | --- |
| 添加查看群图缓存的快捷指令 | 加个 /cache，查看群图缓存 |
| 添加固定回复 | 加个 /hello，固定回复「你好」 |
| 起草群图缓存设置 | 把群图缓存改成 48 小时 |
| 查看已启用的快捷指令 | `/create list` |
| 移除一条快捷指令 | 在创造模式发送 `/create remove /cache`，再确认 |
| 查看模式状态或退出 | `/create status` 或 `/create exit` |

创造模式闲置 15 分钟后退出，确认卡从发起起 10 分钟内有效。退出、过期或重启会让未确认的草稿失效；已确认的快捷指令和设置会保留。QQ 无法显示卡片时，可以按私聊提示用确认码确认。模式内的普通文字用于起草；需要恢复普通对话时，发送 `/create exit`。直接在私聊调整群图缓存仍可使用原有确认流程，无需先开启创造模式。

首版支持预设动作和固定文本，最多保存 12 条快捷指令。已有 QQ 指令及其别名不能被覆盖。群聊和其他账号不能开启模式、使用快捷指令或批准变更。创造模式不运行自定义代码，不增加工具权限；TypeScript 插件仍由维护者验证后走独立发布流程。
